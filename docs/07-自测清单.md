# 7. 自测清单

第一次接入时，从上到下打勾。

## 部署前提

- [ ] 我知道这份完整教程默认 **自建前后端 + Linux VPS + headless + 单用户**
- [ ] 如果是多用户，我已经另外设计凭据、session、进程和数据隔离
- [ ] 如果只是本机 Claude Code，我只照第 1～3 篇，不强行搬 resident 架构

## 最小链路

- [ ] `claude --version` 正常
- [ ] 使用的是测试 Key / 可控额度 Key
- [ ] 当前进程只保留目标 provider 的鉴权
- [ ] `ANTHROPIC_BASE_URL` 没有明显重复路径
- [ ] `ANTHROPIC_MODEL` 是真实存在的模型
- [ ] 最小 `claude -p` 返回 `GATEWAY_OK`
- [ ] 进程返回码为 0
- [ ] Gateway 后台能找到对应时间的请求
- [ ] Gateway 后台显示的实际模型正确
- [ ] Gateway 后台的 usage / 额度 / 账单记录能和这次探针对上

## 鉴权

- [ ] OAuth 登录 / token 签发发生在 Claude / Anthropic 自己的流程里
- [ ] OAuth token 只存在服务端 secret
- [ ] Gateway Key 只存在服务端 secret
- [ ] Key 没有进入浏览器、URL、命令行参数、Git 或日志
- [ ] OAuth 失效时会明确报错，不偷偷切到付费 API
- [ ] API 模式会清掉 OAuth
- [ ] 订阅模式会清掉 API Gateway 鉴权

## 工具与权限

- [ ] Claude Code 真正发起过一次工具调用
- [ ] 工具确实执行成功
- [ ] tool result 成功回到模型
- [ ] 模型在工具回合后正常结束
- [ ] headless 环境不会卡在人工 permission prompt
- [ ] 只暴露确实需要的工具
- [ ] 如果使用 `bypassPermissions`，我知道 `allowedTools` 不会把它锁成白名单
- [ ] 高副作用工具有额外 fence / deny / 审批，而不是只靠 prompt

## 上下文

- [ ] 工具实现仍然复用原来的后端
- [ ] provider 只在 Claude Code 启动边界选择
- [ ] 模型身份拿不到时会明确报错，不偷偷猜
- [ ] 如果关闭 Claude auto compact，我已经有自己的换窗 / Chunk / ContextPlan
- [ ] 我知道 `DISABLE_AUTO_COMPACT` / `CLAUDE_CODE_DISABLE_AUTO_MEMORY` 是当前实现细节，升级要复测

## 会话与 resident

- [ ] 正常连续 Chat 会复用同一个 resident，不会每轮新开
- [ ] 正常热回合不会每轮 `--resume`
- [ ] provider 改变时旧 resident 会退休
- [ ] provider 切换后下一轮会 cold start 新 Claude session
- [ ] 跨 provider 不依赖旧 session `--resume`
- [ ] `--resume` 只用于明确恢复旧 session 的路径
- [ ] 后台 `-p` 使用 one-shot，不污染正式 resident
- [ ] 同一个 resident 的 turn 已经串行化，不会同时写 stdin
- [ ] process dead / idle / timeout 都有明确的回收和恢复路径
- [ ] 用户打断后能区分“还没发给 provider”和“provider 已经开始处理”

## 长期运行

- [ ] thinking（如果启用）正常
- [ ] prompt cache 能看到读写
- [ ] 切 provider 后接受首轮冷启动更慢 / cache 重建
- [ ] 后台 `-p` 任务正常
- [ ] 不会在用户不知情时自动切到付费 provider
- [ ] 日志能看到 provider、model、spawn reason、timeout、usage
- [ ] 日志不会打印完整 token / key

## 版本升级

- [ ] 生产 resident 已明确关闭自动更新（例如 `DISABLE_AUTOUPDATER=1`）
- [ ] 我知道 `DISABLE_UPDATES=1` 会连手动更新一起阻止，通常不需要开得这么死
- [ ] 如果使用 `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`，我知道当前官方文档也把 auto-update 列在它关闭的非必要流量里
- [ ] 升级前记下当前 Claude Code 版本
- [ ] 升级后重跑最小 `-p`
- [ ] 升级后重跑真实工具回合
- [ ] 生产 resident 再测连续两轮
- [ ] 再测 provider 切换 cold start
- [ ] 再测后台 one-shot `-p`
- [ ] 重新确认 permission、session、auto compact 和 cache 行为

## 最后

- [ ] 看过 Gateway 自己的真实账单
- [ ] 确认 Claude Code 显示的 cost 只是参考时，不把它当实扣
- [ ] 测试 Key 用完后已经禁用 / 收回
- [ ] 看过当前 Anthropic 条款和 Gateway 自己的服务条款

如果这些都过了，才适合把它当长期 Gateway 使用。
