# 7. 自测清单

第一次接入时，从上到下打勾。

## 最小链路

- [ ] `claude --version` 正常
- [ ] 使用的是测试 Key / 可控额度 Key
- [ ] 当前进程只保留目标 provider 的鉴权
- [ ] `ANTHROPIC_BASE_URL` 没有明显重复路径
- [ ] `ANTHROPIC_MODEL` 是真实存在的模型
- [ ] 最小 `claude -p` 返回 `GATEWAY_OK`
- [ ] 进程返回码为 0

## 工具

- [ ] Claude Code 真正发起过一次工具调用
- [ ] 工具确实执行成功
- [ ] tool result 成功回到模型
- [ ] 模型在工具回合后正常结束
- [ ] 没有 permission denial

## 准备进项目

- [ ] 工具实现仍然复用原来的后端
- [ ] Key 没有进入前端
- [ ] Key 没有进入 Git / 日志
- [ ] provider 只在 Claude Code 启动边界选择
- [ ] API 模式会清掉 OAuth
- [ ] 订阅模式会清掉 API Gateway 鉴权
- [ ] 模型身份拿不到时会明确报错，不偷偷猜

## 长期运行

- [ ] provider 改变时旧 resident 会退休
- [ ] 下一轮会用新 provider cold start
- [ ] session / resume 正常
- [ ] thinking（如果启用）正常
- [ ] prompt cache 能看到读写
- [ ] 后台 `-p` 任务正常
- [ ] 不会在用户不知情时自动切到付费 provider

## 最后

- [ ] 看过 Gateway 自己的真实账单
- [ ] 确认 Claude Code 显示的 cost 只是参考时，不把它当实扣
- [ ] 测试 Key 用完后已经禁用 / 收回
- [ ] 升级 Claude Code 后准备重新跑一次最小探针

如果这些都过了，才适合把它当长期 Gateway 使用。
